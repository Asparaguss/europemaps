# EuropeMaps

### Offline maps. On your wrist.

EuropeMaps by **Asparagus** brings simplified OpenStreetMap maps, GPX routes and activity recording to compatible Garmin Instinct watches.

## [Install EuropeMaps from the Connect IQ Store](https://apps.garmin.com/apps/f5cd5919-84f9-41b3-b5c7-276a154039bc)

Install and update through Garmin Connect IQ. Check the listing for your exact supported watch. This documentation describes the current Instinct release; experimental ports are not announced as supported devices.

## Features

- Choose a download centre on your phone's map, search for a place, or download around your watch's GPS position.
- Download 2 × 2, 4 × 4, 8 × 8, 16 × 16 or 24 × 24 km areas. Start with 2 × 2 km for a quicker download.
- Import a GPX route and download its map corridor. Select saved routes with their matching corridors.
- Save up to five map areas or route-corridor pairs, with one active at a time, subject to available app storage.
- Follow your GPS position, recenter, zoom and pan. Choose North up or Direction up with more map visible ahead.
- Record walking, hiking or cycling activities; pause, resume and save for normal Garmin Connect synchronization.
- Find backlight, map-name and map-information options under Advanced.

Maps are simplified for the watch's display, memory and storage. Some streets, paths and names may be omitted. Map downloads require your connected phone and internet access; saved maps can be viewed offline.

## Quick start

1. Install EuropeMaps and open it on the watch.
2. Open **Garmin Connect** on your phone, not just the Connect IQ Store app.
3. On the watch, choose **MENU → Download maps → Choose on phone**.
4. Accept the phone link. If it does not appear, press GPS on the code screen with Garmin Connect open. Alternatively, open [Maps & Routes](https://europemaps.duckdns.org/routes) and enter the temporary watch code.
5. Search and **select a result**, or tap the map directly to set the download centre. Review the outlined area, check coverage and start the transfer.
6. Keep EuropeMaps open on the watch and return to Garmin Connect on the phone while the watch downloads.

No map is bundled with a new installation. The optional **Location to Download** field in Connect IQ settings is an alternative search shortcut: the server chooses its centre. Use the website for precise placement.

## Downloads and updates

The official app is distributed through [Garmin Connect IQ](https://apps.garmin.com/apps/f5cd5919-84f9-41b3-b5c7-276a154039bc). This repository contains public documentation and support information; application source code is not published here.

Downloads depend on service availability, storage and shared usage limits. Larger areas can take several minutes. If a limit is reached, try later; saved maps remain available. Update without uninstalling to preserve saved maps and settings.
